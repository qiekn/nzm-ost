一次偶然，把游戏效果音调到了 30%, 背景音乐保持为 100% 。然后打了一局昆仑神宫，体验很棒。

## 技术栈

- **框架**: React 19 + TypeScript (strict mode)
- **构建**: Vite 7 + @vitejs/plugin-react
- **样式**: Tailwind CSS
- **包管理**: pnpm

## 开发

```bash
pnpm install
pnpm run dev
pnpm run build
```

## 快捷键

| 按键 | 功能 |
|------|------|
| `Space` | 播放 / 暂停 |
| `H` 或 `\` | 隐藏 / 显示 UI（全屏欣赏背景视频） |
